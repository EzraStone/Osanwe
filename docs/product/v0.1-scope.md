# Accountless client v0.1

## In scope

### Chat

- Send the full valid conversation transcript on every turn.
- Stream text answers without buffering the whole response.
- Keep conversations ephemeral unless the person explicitly enables local history.
- Let the person stop a request, start a clean conversation, export it, and delete it.

### Code beta

- Keep a code conversation separate from the general Chat conversation.
- Give the provider a bounded coding-assistant instruction.
- State plainly that this beta cannot read files, run commands, or apply changes.
- Do not request file, tool-use, or shell capabilities from the provider.
- Let a person explicitly load generated JavaScript into a timed, network-blocked worker and run
  tests with the local `test` and `assert` helpers.
- Preview HTML only after removing executable and remote-loading elements.

### Models and connection settings

- List only models reported by the connected gateway.
- Explain request format, availability, and privacy posture with factual labels.
- Preserve a model choice locally without storing prompt text in localStorage.
- Avoid ratings or privacy scores that hide important tradeoffs.

- Retain the loopback endpoint and integration examples.
- Remove HTML injection surfaces from copyable snippets.
- Show the live relay, directory, payment, retention, and wallet state without exposing secrets.

### Settings

- Accept a bring-your-own provider key only in the Settings dialog and retain it only in page memory.
- Offer ephemeral and save-on-this-device retention modes.
- Warn that device-only history is readable by other users or malware with access to the browser
  profile.
- Provide complete local deletion and a portable JSON export.

## Explicit non-goals

- Accounts, email addresses, cloud sync, telemetry, analytics, and advertising.
- Card checkout inside the prompt origin.
- Image, audio, file, remote-URL, tool-use, or browsing requests.
- A claim that the gateway operator cannot read prompts before attested execution exists.
- Repository-aware Code tools and any Cowork implementation.
- A latency promise before the Phase 0 campaign is complete.

## Exit criteria

v0.1 is ready for a private test only when:

1. multi-turn context has an automated regression test;
2. all UI assets are local and the CSP contains no unsafe-inline allowance;
3. retention is ephemeral by default and deletion is tested;
4. privacy labels match token and bring-your-own-key runtime state;
5. keyboard-only and screen-reader-critical paths work;
6. Go, frontend, Python, and demo checks pass in CI; and
7. the mint and checkout money path has an end-to-end concurrency/restart review.
